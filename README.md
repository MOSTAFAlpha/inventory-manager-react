# Inventory Manager (React)

A modern, responsive inventory management system built with React for Solo Electronique.

## 🚀 Features

- **Modern UI**: Clean, responsive interface built with React and CSS Modules.
- **Real-time Search**: Instant filtering by product name, reference, or category.
- **Dark Mode**: Built-in dark/light theme toggle.
- **Data Persistence**: Automatically saves changes to local storage.
- **Import/Export**: Support for CSV and JSON data import/export.
- **Statistics**: Real-time dashboard showing total value, item count, and category breakdown.

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: CSS Modules
- **State Management**: React Hooks
- **Icons**: Lucide React

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MOSTAFAlpha/inventory-manager-react.git
   cd inventory-manager-react
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 📝 Usage

- **Add Item**: Use the form at the top to add new inventory items.
- **Edit**: Click on any row to edit item details.
- **Delete**: Use the delete button to remove items.
- **Export**: Use the "Export" button to download a backup of your data.
